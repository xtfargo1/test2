# Volume Booster (Firefox Extension)

Minimalistic Firefox extension that boosts tab audio with an unlimited gain control.

## Usage

1. Load the `extension` folder as a temporary add-on in Firefox (`about:debugging`).
2. Open a tab with audio.
3. Click the Volume Booster icon and set any boost factor (e.g., `2`, `10`, `50`).

The boost factor is stored locally and applied to all tabs that load audio or video elements.
